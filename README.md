# Hospital Patient Management System

## C++ Data Structures and Algorithms Project

### 1. Project Overview

The Hospital Patient Management System is a beginner-friendly C++ console-based project developed to practise and demonstrate Data Structures and Algorithms (DSA) concepts.

The project uses a hospital environment to demonstrate how patient information can be stored, accessed, updated, and managed using C++ vectors.

It will be developed incrementally as new data structures and algorithms are covered during my DSA studies.

### 2. Project Objectives

- Understand how vectors work in C++.
- Practise adding, accessing, updating, and deleting elements.
- Understand vector traversal using different loops.
- Apply programming concepts to a practical hospital scenario.
- Build a portfolio project that demonstrates my understanding of DSA.

### 3. Technologies Used

- **Programming Language:** C++
- **Data Structure:** Vector
- **Code Editor:** Visual Studio Code
- **Version Control:** Git and GitHub

### 4. Concepts Covered

The first module focuses on C++ vectors.

| No. | Concept | Description |
|---|---|---|
| 1 | Vector Declaration | Creating an empty vector |
| 2 | Vector Initialization | Creating vectors with initial values |
| 3 | `push_back()` | Adding elements |
| 4 | `size()` | Getting the number of elements |
| 5 | Element Access | Accessing elements using `[]` and `at()` |
| 6 | `back()` | Accessing the last element |
| 7 | Updating Elements | Modifying existing vector elements |
| 8 | Vector Traversal | Using index-based and range-based loops |
| 9 | Counting Elements | Using a loop and counter variable |
| 10 | `pop_back()` | Removing the last element |
| 11 | `erase()` | Removing an element at a specified position |
| 12 | `empty()` | Checking whether a vector is empty |

### 6. Sample Operations

The current program demonstrates:

- Creating a vector to store patient ages.
- Adding patient ages using `push_back()`.
- Displaying the total number of patients.
- Accessing the first, third, and last elements.
- Updating patient ages.
- Traversing the vector using loops.
- Counting the number of patients.
- Removing elements from the vector.
- Checking whether the vector is empty.

### 7. How to Run the Project

**Step 1:** Clone the repository.

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2:** Navigate into the project folder.

```bash
cd Hospital-Patient-Management-System
```

**Step 3:** Compile the C++ program.

```bash
g++ Module-1-Vectors/vector_basics.cpp -o hospital
```

**Step 4:** Run the program.

```bash
./hospital
```

On Windows, you can run:

```bash
hospital.exe
```
